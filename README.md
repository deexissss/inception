## Description :

    This project is a about understanding docker, and use it for the first time. I learn a lot of new
    tools.
    
    -Virtual Machines vs Docker
        The differences between VM and dockers is that a VM cost a lot of ressources, with the os etc
        Docker only use the package that he really need.
    
    -Secrets vs Environment Variables
        I store credentials in a `.env` file for convenience. While easy to use, this is less secure because variables can be seen in logs or system processes.
        A more secure method (often used in Docker Swarm) where sensitive data is encrypted and only mounted as a file when needed.
        
    -Docker Network : The default. Containers communicate on a private internal network. They are isolated from the host and other networks unless ports are explicitly exposed.
    -Host Network   : The container shares the IP and networking namespace of the host machine directly. This removes isolation and can cause port conflicts on the host.
        

    -Docker Volumes vs Bind Mounts
        Docker volume are managed by docker and sotred in a specific part of the host file system. They are the best way to persist data generated by containers. Bind Mounts is a specific file or directory on the host machine that 
        is mounted into the container. It relies on the host's specific directory structure.

## Instructions :
    Before running the project, you must map the domain name to your local machine.
    Open your hosts file   : `sudo vim /etc/hosts`
    Add the following line : `127.0.0.1 tjehaes.42.fr`
    To execute the project : make
    To clear the project   : make clean
    To delete everything   : make fclean
    To close the docker    : make down

    When the docker is compiled, you can access this site : https://tjehaes.42.fr
